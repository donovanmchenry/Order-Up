# Order-Up
This is a simple card game that puts you in the shoes of a chef who must find the right ingredients for their customers.

Run locally with `python3 -m http.server 8765 --bind 127.0.0.1`, then open [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

The ingredient card photos are stored in `assets/food/`. Their source URLs, creators, and licenses are listed in `credits.html` and `assets/food/sources.json`.
